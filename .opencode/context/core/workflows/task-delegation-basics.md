# Task Delegation Basics

- Delegate only against an approved plan and explicit task boundaries.
- Give each delegate a task-specific context bundle with requirements, constraints, relevant standards, owned files, dependencies, and acceptance checks.
- Split work into small, independently verifiable tasks. Mark dependencies and parallel work clearly.
- Assign non-overlapping file ownership. Agree on shared interfaces before parallel implementation.
- Delegates must not commit, create branches, remove files, or clean temporary data.
- Require a completion report with changed files, checks run and results, and unresolved issues.
- The coordinator reviews all changes and runs integration checks.
- If a delegated task fails, stop and report the failure before proposing a fix.
